# Семинар 10 — стек, очередь с приоритетом и дек
## Задание
1. Разработать алгоритм получения выходного стека, в котором элементы входного стека расположены в обратном порядке.
2. Разработать программу, реализующую очередь с приоритетом.
3. Создать программу, реализующую дек.
